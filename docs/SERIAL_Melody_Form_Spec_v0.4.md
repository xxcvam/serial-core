# SERIAL 旋律与 Form 规格 v0.4

范围：Arp / Lead 动机层 + Form 张力层。**不改音频引擎**（`vKick/vSnare/vHat/vBass/vArp/vLead/vGlitch` 签名与内部实现不动）。
不改：Bass（已认可）、Groove 的鼓组骨架（已认可）。

## 0 结论

1. **v0.3 的 Arp 不是"动机"，是一个 8 元素查表 + 段级常量旋转**：`idx = ARP_MOTIF[(floor(st/2)+rot)%8]`，`rot` 每段只取一次，`ARP_MOTIF` 周期 = 1 小节 → 段内每小节音高序列完全相同。没有"进行"，只有"重复"。
2. **v0.3 的 Lead 是 3 个固定格（0/6/11）+ 五声音阶 + 每格 2.6~5.2 拍长音**：既不成句，也不成动机。Keygen/Trance 的记忆点来自"短动机 + 移位 + 应答"，不是"每小节三个长音"。
3. **Form 的后三段实际是平的**：RISE / CLIMAX / RETURN 的 arp 有效截止全为 2600（`vArp` 内 clamp 饱和），亮度在 RISE 之后零增长；BREAK 只有 1 小节，且 glitch 密度 38% 是全曲最高——"breakdown"比主段更吵。
4. **修法不靠新算法**：音高表（voicing × cycle）、节奏表（mask）、乐句表（cell × phrase × operator）三张表 + 一条互质规则（`gcd(N,L)=1`）。全部可编辑、可复现、可断言。不引入 Markov / L-System。
5. **两套方案已跑通并各有可判定判据**：A 保守（单八度、T/R 算子、Groove 不插 lead），B 激进（八度点、I/RO 算子、Groove 后半应答、E6 高点）。

## 1 为什么 v0.3 不像 Keygen / Trance

### 1.1 量化现状

| 段 | 小节 | 事件/小节 | arp/小节 | lead/小节 | 低频/小节 | 有效均值 cut | 音域均值 | arp 有效 cut |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| INTRO | 2 | 8.00 | 8.00 | 0.00 | 0.00 | 1300 | -7.88 | 1300 |
| GROOVE | 2 | 23.00 | 8.00 | 0.00 | 8.00 | 2100 | -7.88 | 2100 |
| RISE | 2 | 25.00 | 7.50 | 3.00 | 8.50 | 2600 | -4.71 | 2600 |
| CLIMAX | 2 | 32.50 | 8.00 | 3.00 | 9.00 | 2818 | -5.09 | 2600 |
| BREAK | 1 | 12.00 | 7.00 | 0.00 | 0.00 | 900 | -7.29 | 900 |
| RETURN | 2 | 27.50 | 8.00 | 3.00 | 8.00 | 2682 | -5.09 | 2600 |

音域均值单位：半音（相对 A4=440）。有效 cut = 经 `vArp` clamp[850,2600] / `vLead` clamp[1150,3800] 后的实际送值。

### 1.2 六条根因

| # | 根因 | 证据（v0.3 源码行为） | 听感后果 |
|---|---|---|---|
| R1 | **和声静止** | `AM7=[0,3,7,10]` 全曲唯一和弦；`BASS_MOV` 永远落在 Am7 音级 | 36 秒内没有一次"换和弦"，arp 的四音循环听成音型练习 |
| R2 | **周期坍缩到 1 小节** | `ARP_MOTIF` 长 8，配合 `st%2`（八分）→ 8 个八分 = 1 小节 | 每小节完全复读，无"走到下一句"的期待 |
| R3 | **旋转量是段级常量** | `rot = randomFor('arp',sec.id,0,0,mutation)%8`，只含 `sec.id`，不含 `bar` | 段内两小节音高序列逐音相同；只有力度抖动在变 |
| R4 | **概率门冒充编排** | `(R('arp',gate)%100)<96`、`(R('hat',gate)%100)<78`、`(R('glitch',gate)%100)<(sec.id===4?38:12)` | 段与段的差异是掷骰结果，不是设计；同一段换个 Seed 就散架 |
| R5 | **声部不让位** | lead 与 arp 各自按自己的 mask 落格，无互斥判断 | 同一 16 分格上 arp 与 lead 同时发声，动机被淹没 |
| R6 | **亮度饱和 + 音长锁死** | `vArp` 内 `lp.frequency.value=clamp(cut,850,2600)`，且振荡器 `t+0.15` 硬停 | RISE/CLIMAX/RETURN 的 arp 亮度完全相同（都是 2600）；arp 的 gate 长度不是可编辑参数 |

补充：lead 每小节固定 3 音（`EU.lead = euclid(16,3) → 0,6,11`），长度 `2.6/3.9/5.2` 步 —— 三音全落在四分位，全部长音，既无切分也无短促的"驱动音"。

### 1.3 哪几段实际是平的（判定）

| 段 | 判定 | 依据 |
|---|---|---|
| INTRO | **有效** | 8→23 事件/小节，鼓组全静音→全开，真实抬升（用户已认可） |
| GROOVE | **有效** | 唯一有完整鼓组+Bass 的稳定段（用户已认可） |
| RISE | **平** | arp mask 仍是八分（`st%2`），事件/小节 25 vs Groove 23（+9%）；有效亮度 2600 = CLIMAX，等于提前到顶 |
| CLIMAX | **平** | 与 RISE 唯一差别是 `density` 门（92→100）作用在 lead/bass 上；arp 音高、mask、亮度三者与 RISE 全同 |
| BREAK | **反向** | 只有 1 小节 = 1.71s，不足以建立 breakdown；glitch 38%（全曲最高）；无低频留白设计（本来就没 Bass，但也没制造"空"的对比） |
| RETURN | **平** | 有效亮度 2600 与 CLIMAX 相同；事件/小节 27.5 反而高于 RISE，听感是"再放一遍"而非"回落" |

一句话：**v0.3 的张力曲线在 RISE 就到顶，CLIMAX 与 RETURN 只是同一亮度下的密度微调。**

## 2 规则系统

### 2.1 三层架构

```
Form 层（段长 / 逐小节开关 / 亮度曲线 / 八度提升）
  └ Motif 层（arp cycle 表 / lead cell 表 / phrase 表 / operator 表）
      └ Note 层（voicing 取音 / 力度 / gate / 事件写入）
```

三层都可编辑，都不含分支随机：**随机只出现在 Bass（沿用 v0.3 的键与规则）与力度抖动**。arp / lead 的音高完全由表决定。

### 2.2 音高系统（规则 P）

```js
AEOLIAN  = [0,2,3,5,7,8,10]                       // A 自然小调
VOICING  = [[0,3,7,10],    // 0 Am7    A3 C4 E4 G4
            [-4,0,3,7],    // 1 Fmaj7  F3 A3 C4 E4
            [3,7,10,14],   // 2 Cmaj7  C4 E4 G4 B4
            [-2,2,5,7]]    // 3 G6     G3 B3 D4 E4
CHORD_LOOP = [0,1,2,3]
```

- **P1** arp 锚 A3(220Hz)，lead 锚 A4(440Hz)。
- **P2** 和弦按 **小节** 换，不按拍换：`chord = CHORD_LOOP[localBar % 4]`。四小节一循环 = 演奏上的一个"乐句单位"，与 8 小节段长成 2:1。
- **P3** arp 取音只能取 **当前小节 voicing 的音**（含 +12），不得越出 voicing。这条是可断言的不变量。
- **P4** lead 取音走调式级数 `AEOLIAN[deg % 7] + 12*floor(deg/7)`，级数可为负（`T-1/T-2` 会下探），允许跨越到下一八度。
- **P5** A（保守）方案和弦用 `bar%2 ? Fmaj7 : Am7` 二和弦交替；B（激进）用完整四和弦循环。

设计理由：R1 的根因不是"和弦太少"，而是"和弦不换"。四小节一换给出的和声节奏正好落在 Trance/Keygen 的常见尺度（每次换和弦 ≈ 6.9s @140BPM）。

### 2.3 Arp 规则（规则 A）

**A1 符号化**：`mask`（16 位）决定哪些 16 分格发声。当前用到的四个 mask：

| 名称 | 值 | 落点 | 用途 |
|---|---|---|---|
| `S4` | `0x1111` | 0,4,8,12 | 四分脉冲（INTRO 前段、BREAK 首小节） |
| `S8` | `0x5555` | 0,2,4,…,14 | 八分（GROOVE） |
| `S16` | `0x7777` | 0,1,2,4,5,6,8,9,10,12,13,14 | 12/16：3+1 分组（RISE） |
| `FULL` | `0xffff` | 全部 16 分 | 满格（CLIMAX、BREAK 末小节） |

`S16` 不是"少四个音"，是 **3-3-3-3 + 空** 的分组重音，这是驱动感的来源；`FULL` 才是真正的高潮密度。

**A2 位置序号**：`ord` = 该 mask 内第几次命中（0 起）。不是 step 号，是"第几个音"。这样同一张 cycle 表在 4/8/12/16 格 mask 下都成立，换 mask 不用改表。

**A3 查表**：`cycIdx = (localBar * N + ord) % L`，`N = popcount(mask)`，`L = cycle.length`。
`localBar * N` 使每小节起点前进 N 个表位——这就是"进行"；`ord` 使小节内按表走。

**A4 互质律**：要求 `gcd(N, L) = 1`。此时 `(bar*N + ord) % L` 的周期为 `N*L`，一个循环 = `L` 小节。
若 `gcd > 1`，每小节会落回同一子集 → 退化成 R2 的周期坍缩。**这条是唯一必须检查的数学约束。**

| 段 | N | L | 循环长度 |
|---|---:|---:|---:|
| INTRO | 4 | 3 | 12 音 |
| GROOVE | 8 | 5 | 40 音 |
| RISE | 12 | 7 | 84 音 |
| CLIMAX | 16 | 5 | 80 音 |
| BREAK | 4 | 3 | 12 音 |
| RETURN | 12 | 7 | 84 音 |

**A5 cycle 表的值语义**：`vi` 中 `vi % 4` = voicing 内序号，`floor(vi/4)` = 八度抬升。`0..3` 在本八度，`4..7` = 同音级 +12。

```js
ARP_CYCLE = {
  A: { 0:[0,1,2], 1:[0,2,1,3,2], 2:[0,1,2,3,2], 3:[0,3,2,1,3], 4:[2,1,0], 5:[3,1,2,0,1,3,2] },
  B: { 0:[0,1,2], 1:[0,2,1,3,5], 2:[0,1,2,3,2,4,1], 3:[0,3,2,5,1], 4:[2,1,0], 5:[3,1,2,0,1,7,3] },
};
```

**A6 八度点比例**：B 方案每段 cycle 中 `vi >= 4` 的占比 ≤ 25%（实测 0%/20%/14%/20%/0%/14%）。超过这个比例，arp 会侵入 lead 的音域带。

**A7 八度提升（lift）**：段末小节可置 `lift=1`，规则 `if (lift && semi < 8) semi += 12` —— 只抬低音区，保证提升后不与 lead 撞。用于 INTRO→GROOVE、RISE→CLIMAX、CLIMAX 的第 4/8 小节、RETURN 末小节。

**A8 重音**：`accent = (st%4===0 ? 0.07 : st%4===2 ? 0.03 : 0) + (cycIdx===0 ? 0.05 : 0)`。表头音（cycle 第 0 位）额外 +0.05，让每个循环的起点成为可听的"落点"。

**A9 gate 长度的真相**：`vArp` 内音符长度硬编码 `0.145s`，事件层无法改。因此在 arp 上"gate 长度"不是可编辑参数，可编辑的是**占空比（mask）+ 重音（velocity）+ 亮暗（cut）**。要做"断奏感"，用 `S4`/`S8` 的稀疏 mask；要做"连奏感"，用 `FULL` + 高 cut。不要试图传 len。

### 2.4 Lead 规则（规则 L）

**L1 Cell 表**：cell = 一小节内的落格 + 每音长度。

| Cell | steps | 每音长度（16 分步） | 角色 |
|---|---|---:|---|
| `HOLD` | [7] | 8.0 | 悬置长音（BREAK 用） |
| `ANTE` | [3,11] | 3.0 | **提问**：后半拍两音 |
| `RESP` | [2,8,14] | 2.0 | **应答**：落在第 3 拍与末 16 分 |
| `PUSH` | [1,5,9,13] | 1.6 | 推进：弱位四连 |
| `ROLL` | [1,3,5,7,9,11,13,15] | 1.2 | 滚奏：8 连（只在高潮/入 drop 用） |

`RESP` 的 `[2,8,14]` 是刻意选的：Bass 的 euclid 落点是 `0,4,7,10,13`，`2/8/14` 全部避开 → 应答不被低频顶掉（实测重合率 ≤ 22%）。

**L2 Phrase 表**（调式级数，句末落点是有意设计的）：

```js
PHRASE = {
  A: [0,2,4,1],   // A C E B  → 落 9 度，悬（接下一句）
  B: [4,3,2,0],   // E D C A  → 落主音（收）
  C: [0,4,5,6],   // A E F G  → 落 7 度，推进（RISE 专用）
  D: [6,4,3,2],   // G E D C  → 落 3 度，软收（BREAK 专用）
};
```

段落与乐句的绑定不是随机的：**RISE 只用 C（推进型），CLIMAX 只用 B（收束型），RETURN 混合 B/A/D**。这是"同一动机在不同张力下的两种收尾"。

**L3 Operator 表**（对整句做变换）：

| 算子 | 含义 | 用途 |
|---|---|---|
| `''` | 原样 | 陈述 |
| `T+1` / `T+2` / `T-1` / `T-2` | 级数整体移调 | 模进（sequence） |
| `R` | 逆行 | 同一动机的反向陈述 |
| `I` | 倒影（绕首音） | 激进方案专用 |
| `RO` | 逆行 + 末音 +7 | 激进方案的高点制造 |

**L4 句法**：`ANTE` 落在 bar n，`RESP` 落在 bar n+1 —— 一小节提问、一小节回答。这是唯一的"调用-应答"形式，且由 cell 表强制，不靠随机。

**L5 密度**：A 方案 lead ≤ 4 音/小节（不铺满）；B 方案允许 `ROLL` 的 8 音，但只在 RISE 末小节与 CLIMAX 末小节。

**L6 音域**：A ≤ B5（semi 14），B ≤ E6（semi 19）。超过 E6 在 140BPM 的失真 lead 音色上会刺耳且与小调色彩冲突。

### 2.5 声部礼让（规则 M）

- **M1** lead 先写，占格；arp 遍历时 `if (leadOn[st]) continue` —— **同一 tick 不允许 arp 与 lead 同时发声**（可断言）。
  关键细节：`ord++` 发生在 `continue` **之前**，所以被 lead 占掉的格子仍然推进 arp 的表位。arp 的旋律线在"被静音"时保持连续，不会因为让位而错位——这是让位规则不破坏动机完整性的前提。
- **M2** lead 落点与 Bass 落点的重合率 ≤ 1/3（实测 A: 17%/14%/0%/0%，B: 0%/22%/16%/0%/9%）。
- **M3** arp 与 lead 的音域带分离：arp 主带 A3–G4，lead 主带 A4–E5；B 方案的八度点允许 arp 触及 C5/E5，但占比 ≤ 25%。

### 2.6 可编辑表清单

| 想改什么 | 改哪 | 不需要动 |
|---|---|---|
| 和弦进行 | `VOICING` + `CHORD_LOOP` | 任何代码 |
| arp 音型 | `ARP_CYCLE.A/B` 的数组（保持 `gcd(N,L)=1`） | 任何代码 |
| arp 节奏密度 | 段的 `arpMask` | 任何代码 |
| 旋律动机 | `PHRASE` / `LEAD_CELLS` | 任何代码 |
| 句法变化 | 段的 `cells/op` 表 | 任何代码 |
| 张力曲线 | 段的 `cut` 数组、`lift` 数组 | 任何代码 |
| 鼓组进出 | 段的 `kick/snare/hat/glitch` 开关数组（0/1） | 鼓组骨架本身 |

### 2.7 确定性

| 层 | 随机源 | 说明 |
|---|---|---|
| arp 音高 / lead 音高 | **无** | 纯表驱动，同 Seed 同表 → 逐位一致 |
| arp 力度 | `R32(purpose=velocity, attempt=1)` | 每音独立，±0.02 |
| Bass | `R32(gate/pitch/velocity)` | 与 v0.3 **同一套键**，逐位不变 |
| hat / glitch | `R32(gate)` | 与 v0.3 同规则 |
| 鼓组骨架 | 无 | euclid / 手写常量 |

只用到 purpose 1/2/3，没有新增 purpose。校验和 `form_hash` 的三作用域不受影响；`generatorVersion` 需从 v0.3 升到 v0.4（arp/lead 生成规则变了）。

## 3 Form 六段张力设计

### 3.1 总表（v0.4 B，36 小节 = 61.7s）

| 段 | 小节 | 角色 | arp mask | arp/小节 | lead/小节 | 低频/小节 | 有效 cut | 音域均值 | 八度提升 |
|---|---:|---|---|---:|---:|---:|---:|---:|---|
| INTRO | 4 | 建立和声，无鼓 | S4,S4,S8,S8 | 6.00 | 0.00 | 0.00 | 900→1200 | -4.83 | 末小节 |
| GROOVE | 8 | 锁定律动 | S8 ×8 | 7.25 | 1.25 | 8.00 | 1700→2150 | -4.13 | 无 |
| RISE | 4 | 抬升，16 分进入 | S16 ×4 | 9.00 | 4.50 | 8.75 | 2000→2400 | -0.39 | 末小节 |
| CLIMAX | 8 | 满格 + 高点 | FULL ×8 | 12.00 | 4.00 | 9.00 | 2400→2600 往返 | -0.80 | 第 4/8 小节 |
| BREAK | 4 | 真空 → 构建 | S4,S8,稀疏,FULL | 8.00 | 0.50 | 1.00 | 1200/950/850 → 扫 900→2500 | -8.74 | 无 |
| RETURN | 8 | 回落，不复制高潮 | S16,S16,S8×6 | 7.88 | 2.88 | 8.13 | 2500→2050 | -1.41 | 末小节 |

### 3.2 逐段设计

**INTRO（4 小节）**
- 只有 arp。mask 递进 `S4 → S4 → S8 → S8`：前两小节四分脉冲（每次只有 4 个音，留出空间），后两小节切八分。
- cut 线性 900→1200：**唯一从很暗开始的段**，给 GROOVE 留出 700Hz 的抬升余量。
- 末小节 `lift=1`：整个 arp 抬一个八度，作为"进门"的钩子。
- 和弦：`Am7 → Fmaj7 → Am7 → Fmaj7`（A 方案）/ 四和弦（B 方案）。第一小节必须是 Am7 —— Bass 的根音是 A1，进段要同根。

**GROOVE（8 小节）**
- 鼓组骨架与 v0.3 逐位一致（`EU_KICK`/`[4,12]`/`EU_HAT` + 78% 门），这是"已认可"的部分，不改。
- arp 全部 `S8`，八分密度恒定；cut 从 1700 缓慢爬到 2150，不跳跃。
- **A 方案：整段无 lead**（已认可段落零改动）。**B 方案：第 5–8 小节插入 `ANTE/RESP`**，即"Groove 后半开始有人声部提问"，为 RISE 铺路。

**RISE（4 小节）**
- arp 换 `S16`（12/16：3+3+3+3 的空隙分组）→ arp/小节 9.00。
- lead 从第 1 小节就进入，用 `PHRASE C`（推进型，落 7 度）+ 逐小节移调 `'' → T+1 → T+2 → T+2`。
- A 方案 `PUSH/PUSH` 收尾；B 方案末小节换 `ROLL` → **8 连 16 分滚奏**，是进 CLIMAX 的最强预备。
- cut 2000→2400，末小节 `lift=1`。

**CLIMAX（8 小节）**
- arp 全 `FULL`（16 音/小节，arp/小节 12.00），八度点在 B 方案里到 C5/E5。
- cut 在 2400↔2600 之间**往返**（不是单调爬升）：第 1/5 小节 2400 略微回落，制造 2 小节一次的呼吸，避免 8 小节持续顶到 clamp 造成的听觉疲劳。
- lead 用 `PHRASE B`（收束型）+ `RESP/PUSH` 交替，第 4/8 小节 `lift`；B 方案末小节 `ROLL` 且算子 `RO` → 出现 E6 高点。
- glitch 只在 CLIMAX 全段开启（12% 门控）。

**BREAK（4 小节）**——这是 v0.3 最需要重做的段

| 小节 | 内容 | 目的 |
|---|---|---|
| 1 | arp `S4`（4 音）+ `HOLD` 长音，cut 1200 | 抽掉所有鼓，只留骨架音 |
| 2 | arp `S8` + hat 单点，cut 950 | 帽子进一半，暗示"还在" |
| 3 | **真空**：只有 4 个 arp 音（`0b111100` → 2,3,4,5），cut 850 | 全曲最空的一小节；低频 0 |
| 4 | arp `FULL` + cut 逐 16 分从 900 扫到 2500 + **snare 16 分滚奏** + kick 回归 + glitch | 4 小节构建，直接推入 RETURN |

- 低频（kick+bass）在 BREAK 只出现在第 4 小节：实测 BREAK 低频 = CLIMAX 的 11%（≤20% 达标）。
- **glitch 在 BREAK 前 3 小节全关**。v0.3 把 38% 的 glitch 塞进唯一 1 小节的 breakdown，是"breakdown 比主段更吵"的直接原因。
- 这是全曲**唯一**合法的滤波上行（因为 `vArp` 无包络，逐音 cut 变化是唯一的"扫频"手段，听感是阶梯上升而非滑音——在此风格可接受）。

**RETURN（8 小节）**
- arp `S16,S16,S8×6`：前两小节保持 16 分（不立刻掉），再退回八分。
- cut 2500→2050 **单调下行**：与 CLIMAX 的往返形成对比，听感是"退场"而不是"再高潮"。
- lead `RESP/ANTE` 交替 + `PHRASE B/A/D` 混合，算子 `R`/`T-1`。
- 末小节 `lift`，为循环回 GROOVE 留钩子。

### 3.3 v0.3 的平坦段（复述，判定依据见 §1.3）

RISE / CLIMAX / RETURN 三段 arp 有效亮度全为 2600；BREAK 反向（更吵且过短）。INTRO / GROOVE 有效。

## 4 与 Bass 的关系

Bass 已认可，`BASS_MOV=[0,0,0,3,5,7,10]`、`EU_BASS=euclid(16,5)→0,4,7,10,13`、`len=2.2/1.4`、力度 0.55~0.80，全部原样保留。其余声部**围绕它**组织：

### 4.1 频域分配

| 声部 | 主频带 | 依据 |
|---|---|---|
| Bass | A1–G2（55–98Hz），基频 + 2 次谐波 | `BASS_ROOT=55` |
| Kick | 60–80Hz 冲击，与 Bass 同拍但短 | `0,4,8,12` 与 Bass 的 `0,4,...` 部分重合（低频同拍是 house/trance 的常态，不算冲突） |
| Arp | A3–G4（220–392Hz），B 方案允许点到 C5/E5 | 锚 A3 |
| Lead | A4–E5（440–659Hz），B 方案到 E6(1318Hz) | 锚 A4 |
| Hat / Glitch | 6kHz+ | 无低频能量 |

### 4.2 和声

- Bass 永远是 Am7 骨架音（A/C/D/E/G 五个音级，不含 F/B）。因此**其余声部的色彩只能做"加音"，不能做"改根"**。
- `VOICING` 的四个和弦全部与 A/C/D/E/G 兼容：Am7（同）、Fmaj7（A=3rd, C=5th）、Cmaj7（C=根, E=3rd, G=5th）、G6（G=根, B=3rd, D=5th, E=6th）。F3 与 B4 是仅有的两个"色彩音"，它们在 arp 的低八度出现（F3）和高八度出现（B4），不会在 Bass 频段造成浊音。
- 换和弦的落点与小节对齐，**Bass 的 5 拍 euclid 不随和弦改变**——这是刻意的：低频保持不变，和声色彩在上方流动，符合"Bass 是地基"的设计。

### 4.3 低频空间规则

- **B1** arp 不得低于 A3（220Hz）。`VOICING` 中 F3(174Hz) 是唯一例外，且只在 arp 上出现，不与 Bass 的 F 频段冲突（Bass 没有 F）。
- **B2** lead 落点避开 Bass 落点（§2.5 M2，实测重合率 ≤ 22%）。
- **B3** BREAK 前 3 小节 Bass 与 Kick 全关，制造真正的低频真空；第 4 小节 kick 先回、Bass 下一段才回——"鼓先回来，贝斯后回来"是 drop 前的标准手法。
- **B4** CLIMAX 的 arp 八度点（C5/E5）不与 lead 的 A4–E5 主带冲突：arp 是短音（0.145s）且 cut 更低，lead 是长音高 cut，两者在时间与亮度上可分辨。

## 5 两套 A/B 方案

### 5.1 差异

| 维度 | A 保守 | B 激进 |
|---|---|---|
| 和弦 | `Am7 ↔ Fmaj7` 二和弦交替 | 四和弦循环 `Am7→Fmaj7→Cmaj7→G6` |
| arp cycle | 全部 `vi < 4`（单八度） | 允许 `vi ≥ 4`，占比 ≤ 25% |
| GROOVE 的 lead | **无**（已认可段落零改动） | 第 5–8 小节 `ANTE/RESP` |
| RISE 末小节 | `PUSH`（4 音） | `ROLL`（8 音滚奏） |
| CLIMAX 末小节 | `PUSH` + `T+2` | `ROLL` + `RO`（E6 高点） |
| 算子集 | `T±1/T±2/R`（无 I/O/RO） | 含 `I`/`RO` |
| lead 上限 | B5（semi 14） | E6（semi 19） |
| lead 密度 | ≤ 4 音/小节 | 最多 8 音/小节 |

### 5.2 判据（可自动断言，33 条见参考实现）

**共同判据（两方案都必须过）**
1. arp 音级 100% 落在当前小节 voicing 内（含 +12）。
2. 每段 `gcd(N, L) = 1`。
3. Bass 与 v0.3 逐位一致（各段前 2 小节）。
4. 鼓组骨架（kick/snare/hat）与 v0.3 逐位一致（各段前 2 小节，含 hat 78% 门与 open 位）。
5. 同一 tick 不同时出现 arp 与 lead。
6. lead 与 Bass 落点重合率 ≤ 1/3。
7. arp 有效 cut：INTRO < GROOVE < RISE < CLIMAX 严格递增。
8. BREAK 低谷（前 3 小节）比 GROOVE 暗 ≥ 30%；CLIMAX / BREAK 低谷 ≥ 2.4×。
9. BREAK 末小节峰值 ≥ 低谷 2.4× 且 ≥ CLIMAX 均值的 90%。
10. BREAK 低频 ≤ CLIMAX 的 20%；BREAK 末小节 snare ≥ 10（滚奏）。
11. glitch 只出现在 CLIMAX 全段与 BREAK 末小节。
12. 同 Seed 重建逐位一致；A/B 产生不同 PAT。

**A 专属**
- GROOVE 段 lead 事件数 = 0。
- 算子集不含 `I/O/RO`。
- lead 每小节 ≤ 4 音。
- 最高音 ≤ B5。

**B 专属**
- GROOVE 第 5–8 小节 lead 事件数 > 0。
- CLIMAX 最高音 ≥ E6（semi ≥ 19）。
- RISE 末小节 lead 恰为 8 音。
- arp 每段 `vi ≥ 4` 占比 ≤ 25%。

### 5.3 人耳 A/B 的听点（自动断言之外）

| 听点 | 期望（A） | 期望（B） |
|---|---|---|
| Groove 是否被破坏 | 完全不变 | 后半有人声部进来，需确认"不抢" |
| RISE 是否有"要炸"的预感 | 中（模进 + 推进句） | 强（8 连滚奏） |
| CLIMAX 的记忆点 | 无高点，靠密度 | E6 一次，之后不再重复 |
| BREAK 是否真空 | 是（第 3 小节 4 个音） | 是 |
| RETURN 是否"回落"而非"再来一遍" | 是（cut 下行 + 八分） | 是 |

建议先做 A（风险低，Groove 零改动），B 作为"更高能量版本"的候选。
